PhotoR3 es una aplicación para Android diseñada con herramientas y calculadoras útiles para fotógrafos.

Este proyecto es completamente gratuito y libre de publicidad o virus. 

Nace como un gesto de agradecimiento a todo lo que he aprendido de miles de fotógrafos a lo largo de los años, con la esperanza de que ahora sea de utilidad para muchos otros. 

Al no ser un software profesional, se comparte "tal cual" para que lo uses a tu conveniencia.

Puntos clave a tener en cuenta:
• **Siempre gratis**: Si alguien te ha cobrado por esta aplicación, reclama tu dinero de inmediato. 
• **Última versión**: Recuerda que la versión más reciente siempre estará disponible en este repositorio de GitHub.
• **Comparte**: Su único objetivo es ayudarte a capturar mejores fotografías. Si te resulta útil **NO DUDES EN COMPARTIR** CON OTROS FOTOGRAFOS, me hará ilusión ver a otros fotógrafos usando la aplicación.
