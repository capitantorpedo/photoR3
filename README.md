# photoR3
¿Buscas una herramienta precisa para tus sesiones? 

PhotoR3 es una calculadora para fotógrafos 100% gratuita y sin anuncios. 
He desarrollado esta aplicación como un proyecto personal para apoyar a la comunidad y agradecer todo el conocimiento que me han brindado estos últimos años. 

¡Espero que te sea de gran utilidad!, comparte la aplicación, me hará feliz ver como otros fotógrafos la usan.
